# shared-skills

公共技能仓库，集中维护可复用的 AI 技能文档、提示词模板和协作约定。

## 目录说明

- `skills/`：按主题分类的可复用 skill。
- `skills/<name>/skill.md`：单个 skill 的主文档。

## 当前可用技能

- `skills/andrej-karpathy/skill.md`：Andrej Karpathy 风格的编码与协作准则中文版。

## 编写建议

- 一个 skill 保持一个明确目标，不要把多个场景混在一起。
- 优先写清楚适用场景、执行规则、验证方式和输出要求。
- 尽量复用现有项目规范，避免和项目本身的约束冲突。
